# 千问办公实战蓝皮书

**从第一个任务，到一套 AI 办公习惯**

📖 在线阅读：**https://6ackpacks.github.io/**（根域名，推荐）

🪞 镜像：https://6ackpacks.github.io/QwenOfficeGuide/

> 这不是官方功能说明书的改写，而是一本以真实任务为主线的实战读本。先完成登录和第一项交付，再进入钉钉协作、数据分析、网页交付和定时自动化，最后把一次成功变成团队可复用的工作系统。

## 你会在这里看到什么

| 部分 | 内容 |
| --- | --- |
| 第一篇 · 使用手册 | 入口登录、界面、第一个任务、模型与积分、专家套件、钉钉集成、连接器、定时任务 |
| 第二篇 · 案例篇 | 办公三件套、数据分析、调研、网页交付、多模态、会议、早报、电商、自媒体、本地文件 |
| 第三篇 · 进阶篇 | 打造 Skill、多任务编排、自动化可靠性 |
| 第四篇 · 岗位与行业 | 不同岗位的使用路线和行业工作流 |
| 附录 | 常用指令模板与场景速查表 |

## 推荐阅读方式

- **第一次使用**：从第 1 章开始，按顺序完成第一篇。
- **已经有具体任务**：直接进入第二篇对应案例，跑通后再阅读第三篇。
- **准备团队落地**：重点阅读第三、四篇，并记录权限边界、验收标准和失败回退。

## 本地阅读与开发

需要 Node.js 20～24，推荐 Node.js 22。

```bash
npm install
npm run dev
```

本地构建：

```bash
npm run docs:build
npm run docs:preview
```

## 部署

站点为 VitePress 静态构建，推荐部署到 Cloudflare Pages，详见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## 内容边界声明

- 本站是**独立编写的实践手册，不是千问办公官方网站**。产品入口、套餐、权限与实际开放能力，以千问办公官网 qwenwork.cn 和当前账号界面为准。
- 写作过程中参考了千问办公官网（qwenwork.cn）公开信息，以及社区第三方资料（如千问办公小绿书 qwenwork.org）；具体产品细节如有出入，以官方为准。
- 书中提示词均为教学模板，执行前请替换为自己的真实材料，并遵守所在组织的数据安全制度。
