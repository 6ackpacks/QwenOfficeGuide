# 第 23 章 岗位路线图：不同岗位如何用深千问办公

岗位应用不应从"这个岗位有哪些提示词"开始，而应从三个问题开始：哪些工作重复发生，哪些产物有稳定标准，哪些决定必须由人承担责任。

## 岗位应用的四级成熟度

| 等级 | 工作方式 | 典型形态 | 进入下一级的条件 |
|-|-|-|-|
| L1 单次辅助 | 人给完整材料，AI 生成草稿 | 纪要、摘要、表格、PPT | 输出可验收，连续成功 3 次 |
| L2 固定模板 | 使用任务模板和标准输出 | 周报、复盘、客户简报 | 输入字段和验收规则稳定 |
| L3 工作流 | 技能、网盘、连接器协作 | 内容流、报表流、调研流 | 有负责人、日志和异常处理 |
| L4 团队能力 | 套件分发、定时任务运行 | 部门级自动化 | 权限、成本和资产治理到位 |

每个岗位都应从 L1 的低风险任务开始。低频、差异大或责任重的工作，保持"AI 辅助 + 人工决策"更合理。

## HR 与行政

| 场景 | 输入 | 交付物 | 必须控制 |
|-|-|-|-|
| 简历初筛摘要 | 简历、岗位要求 | 匹配度摘要、面试问题建议 | 不自动淘汰候选人 |
| 制度 FAQ | 已批准的制度文件 | 员工常见问题解答 | 版本日期和适用范围 |
| 入职材料包 | 入职清单模板 | 学习路径、材料清单 | 员工个人信息最小化 |
| 考勤与审批整理 | 钉钉考勤、审批记录 | 汇总表、异常清单 | 只汇总不做处罚判断 |

## 法务与合规

| 场景 | 交付物 | 人工关口 |
|-|-|-|
| 条款提取与对照 | 条款清单、版本差异表 | 律师复核每条结论 |
| 合同台账 | 合同要素台账（主体、金额、期限） | 关键要素双检 |
| 合规材料预检 | 材料完整性清单 | 不替代法律意见 |
| 案例检索整理 | 公开案例摘要与来源 | 引用可追溯 |

千问办公的企业法务、合同管理套件可作起点，但**法律判断的责任永远在人**。

## 财务与税务

| 场景 | 推荐做法 | 必须控制 |
|-|-|-|
| 发票与账单整理 | 识别、登记、核对三单一致 | 金额逐笔人工抽核 |
| 预算执行分析 | 差异分析、异常清单 | 口径先书面确认 |
| 月结材料流水线 | 模板化生成初稿 | 关账前专人复核 |
| 报表生成 | 标准格式报表 | 公式可刷新、可追溯 |

财务场景的纪律：AI 可以整理和呈现，**确认与签字必须是人**。

参考第 18 章的闭环路线：选题池 → 成稿 → 多平台适配 → 复盘。套件侧可用内容增长 GROWTH KIT 起步。

## 教师与培训师

| 场景 | 交付物 | 注意点 |
|-|-|-|
| 教案与课件 | 教案、PPT 课件 | 知识点准确性人工把关 |
| 作业与题库 | 分层题目、评分要点 | 题目原创性与版权 |
| 学情分析 | 成绩分析报告 | 学生数据隐私保护 |

## 分析师与投研

投研分析套件覆盖读年报、行业研究、纪要整理和可比公司分析。纪律：数据来源与时间戳必须标注，估值与投资建议必须人工负责。

## 落地三步走

1. **第一周**：选 1 个重复任务，用第一篇的方法跑通 3 次。
2. **第一个月**：把它模板化（L2），固定输入和验收标准。
3. **一个季度**：评估是否升级为工作流或套件（L3/L4），并指定负责人。
