# 第 24 章 行业路线图：从通用能力到行业工作流

行业落地不是给 AI 换个行业名词，而是回答：这个行业里哪些文档最重、哪些流程最重复、哪些环节最怕错。

## 通用能力到行业工作流的映射方法


## 行业落地的四个问题

1. **这个行业的"事实来源"在哪？** 是 ERP 导出、纸质单据拍照，还是群聊记录？事实来源决定任务设计。
2. **哪些环节有监管要求？** 医药、金融、公共服务等行业的产物可能有合规审查，AI 产物要预留审查关口。
3. **术语表有没有？** 行业黑话、编码规则先整理成术语表给千问办公，输出质量会明显提升。
4. **谁来做第一个试点？** 选愿意尝新、且任务重复度高的同事，跑通后再推广。

## 一个制造业的完整示例

```text
背景：我们是一家五金件厂，质检员每天手写质检记录，月底汇总要加班两天。
目标：把质检记录变成电子台账，月底自动汇总。
方案：
1. 质检员拍照上传记录表，千问办公识别并写入 Excel 台账；
2. 识别结果先由质检员确认再入账（人工关口）；
3. 每月 1 日定时任务汇总：合格率、不良 top5、趋势图；
4. 汇总报告发给生产经理。
验收：连续两周台账与纸质记录一致率 100%。
```

## 避坑清单

- 不要一开始就追求全流程自动化，先自动化最痛的单点。
- 监管行业的 AI 产物必须留审查记录。
- 术语表、口径文档这些"无聊"的资产，恰恰是行业落地的地基。
- 试点成功后把方法写成 Skill（第 20 章），别让经验留在个人手里。
