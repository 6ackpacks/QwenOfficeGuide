# 第 7 章 钉钉深度集成：企业 IM 能力闭环

千问办公把企业协作能力直接建在钉钉链路上：官方口径是 **25 项企业 IM 能力**，覆盖消息群聊读取、考勤审批、会议日程、文档表格生成、知识库与邮件，让信息查询、内容生产与流程处理在企业协作链路中闭环完成。

## 钉钉里能做什么

| 能力组 | 典型操作 | 交付物 |
|-|-|-|
| 企业 IM 消息 | 读取和汇总消息群聊 | 群消息摘要、周报素材 |
| 日程会议 | 查询、创建、调整日程与会议 | 会议安排、冲突提醒 |
| AI 听记 | 整理会议听记内容 | 纪要、待办、结论清单 |
| 文档表格 | 创建钉钉文档与 AI 表格 | 协作文档、台账 |
| 待办 | 创建、分派、跟踪待办 | 任务清单与提醒 |
| 考勤审批 | 查询考勤、发起或整理审批材料 | 审批单、考勤汇总 |
| 知识库 | 读写钉钉知识库内容 | FAQ、制度摘要 |
| 邮件 | 起草和处理邮件 | 邮件草稿 |

具体可用项以当前账号和组织配置为准——企业管理员可能关闭了部分能力。

## 三个高频场景

### 场景一：群消息变周报

```text
请读取【项目组群】最近一周的消息，按"进展、风险、待办、需要决策"四类整理，
输出周报 Word 初稿。要求：
1. 每条进展标注来源发言人和日期；
2. 风险项如果消息里没有结论，标"待确认"，不要替我们下结论；
3. 待办必须落到具体人名，找不到负责人的单独列出。
```

### 场景二：一句话建日程

```text
帮我在下周二或周三下午找一个 1 小时的空档，创建"Q3 复盘会"，
邀请产品组全体成员，议程写上：数据回顾、问题归因、Q4 目标对齐。
如果两个时段都有冲突，把冲突情况告诉我，不要自动改期别人的日程。
```

### 场景三：审批材料预检

```text
我要发起一笔采购审批。请根据这份报价单和采购制度文档，
检查：金额是否超过需要加签的阈值、材料是否齐全、流程上缺什么。
只给检查清单，不要替我提交审批。
```

## 边界：钉钉数据的三个纪律

1. **读取群聊有范围**。只读取你有权限且任务确实需要的群；不要默认让 AI 扫描所有群聊。
2. **涉及人的信息最小化**。考勤、绩效、薪酬类信息能不用就不用，必须用时先确认公司制度允许。
3. **外发动作必须人工确认**。发消息、发通知、提交审批、群发文档，这些动作在千问办公请求授权时逐项看清再放行。

## 桌面端与 IM 频道

如果你用桌面客户端，还可以通过 **IM 频道**把千问办公接入钉钉、飞书、微信、Slack 等消息平台，在熟悉的消息窗口里发起和接收任务结果。接入方式和可用平台以当前客户端为准（第 9 章展开）。
