# 第 8 章 连接器、浏览器自动化与电脑操作

千问办公的"手脚"来自三类能力：连接器（对接外部系统）、浏览器自动化（操作网页）和电脑操作（操作桌面应用）。这一章讲清楚各自适合什么、怎么授权、边界在哪。

## 三类能力的分工

| 能力 | 作用 | 典型任务 | 前提 |
|-|-|-|-|
| 连接器 | 对接外部系统与数据源 | 电商平台、MCP 服务、第三方工具 | 在扩展页开启并完成授权 |
| 浏览器自动化 | 在浏览器里打开网页、点击、填表、抓取 | 查价格、抓公开资料、登录后操作网页 | 桌面客户端，浏览器连接器开启 |
| 电脑操作 | 读取可见界面，模拟鼠标键盘操作桌面应用 | 跨应用整理信息、必须走图形界面的步骤 | macOS，系统辅助功能等权限授权 |

选择顺序：**有 API 或连接器优先用连接器；网站任务优先用浏览器连接器；只有没有合适接口的桌面应用，才用电脑操作。**

## 连接器与 MCP

连接器在扩展页管理。常见的连接对象：

- 电商平台后台（如 1688、淘宝天猫）：选品、商品洞察、经营分析。
- 社交媒体平台（如小红书）：内容数据聚合。
- MCP 服务：以标准协议接入更多第三方工具。

每接一个连接器，问自己三个问题：它能读到什么？它会写到哪？授权随时能收回吗？

## 浏览器自动化

浏览器自动化让千问办公像人一样使用网页：打开页面、滚动、点击、输入、截图、提取内容。

适合的任务：

- 收集公开信息：价格、榜单、政策原文、竞品信息。
- 登录后操作：在自己账号里完成有固定路径的网页操作。
- 网页验证：检查自己发布的网页是否正常显示。

一个稳妥的任务描述：

```text
请用浏览器打开【某公开榜单页】，提取前 20 条的标题、作者和发布时间，
整理成 Excel。要求：
1. 只读取公开可见内容，不要尝试登录或绕过任何限制；
2. 每行注明来源链接；
3. 如果页面结构变化导致提取失败，停下来告诉我，不要猜测数据。
```

## 电脑操作（Computer Use）

电脑操作让千问办公读取可见界面，并通过鼠标、键盘和快捷键操作没有合适 API 的桌面应用。它适合跨应用整理信息、调整系统设置或完成必须经过图形界面的步骤。

使用前提（以 macOS 为例）：

1. 在连接器中开启电脑操作。
2. 按系统提示完成辅助功能、屏幕录制等权限授权。
3. 执行过程中保持关键操作可见，高危步骤等待确认。

电脑操作的三条纪律：

- **先备份再动手**：涉及文件移动、删除、覆盖的任务，先让 AI 列出操作清单，确认后再执行。
- **不要无人值守跑高危操作**：电脑操作执行时人最好在旁边，至少把执行过程记录下来。
- **范围最小化**：只授权当前任务需要的应用和目录。

## Hooks 自动化钩子

较新版本提供 Hooks 能力，可以在特定事件发生时自动触发预设动作（例如任务完成后推送结果）。配置入口与可用事件以当前端为准，建议先从"完成后通知"这类只读钩子用起。
