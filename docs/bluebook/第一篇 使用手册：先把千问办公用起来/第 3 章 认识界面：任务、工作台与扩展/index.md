# 第 3 章 认识真实界面：从新任务开始

千问办公以对话任务为核心。不同使用端的外层界面并不完全相同：钉钉内会保留钉钉自己的导航，独立网页端和桌面端也会有各自的功能入口。本章以官方帮助中心当前展示的**钉钉内网页版**为例，只说明截图中能够确认的界面元素。

> 产品会持续更新。如果你的账号所见与截图不同，请以当前界面和[千问办公官方帮助中心](https://qwenwork.cn/docs)为准；套餐、组织权限和灰度发布也可能影响入口是否出现。

## 当前官方界面

![千问办公钉钉内网页版界面：左侧包含新任务、扩展、定时任务、我的网页、个人网盘和最近任务，主区域为任务输入框](/images/qwenwork-official-interface.webp)

*截图来源：千问办公官方帮助中心“千问办公简介”，抓取于 2026 年 8 月 13 日。画面中的头像与账号信息已经由官方截图隐去。*

截图可以分成三层：

1. **最左侧是钉钉导航**，包括消息、通讯录、文档、AI 表格、工作台、会议、日历、待办和 DING 等。这是钉钉的外层界面，不是千问办公自己的功能菜单。
2. **中间左侧是千问办公导航**，当前截图可见新任务、扩展、定时任务、我的网页、个人网盘和最近任务。
3. **右侧是任务区**，中央输入框用于描述任务、添加材料和选择当前可用模型。

## 千问办公导航里有什么

| 截图中的入口 | 可以确认的作用 |
| --- | --- |
| 新任务 | 创建一次新的 AI 任务或对话 |
| 扩展 | 进入能力资源区；截图中展开为专家套件、技能和连接器 |
| 定时任务 | 创建和管理在云端按计划执行的任务 |
| 我的网页 | 管理与 AI 交互过程中生成并发布的网页 |
| 个人网盘 | 存储上传文件以及千问办公生成的产物 |
| 最近任务 | 返回历史任务，查看结果或继续对话 |

这些名称来自官方截图与帮助中心，不代表每个端、每个账号都会同时出现全部入口。例如，电脑操控属于桌面端能力，企业管理后台只面向有相应权限的管理员。

## 新任务输入区

新任务页面的主体是输入框。官方截图中可以直接看到：

- 左下角的 **“+”按钮**，用于添加任务需要的材料；
- 旁边的工具入口图标；
- 右下角当前显示为“高级”的**模型选择入口**；
- 输入框下方的任务建议，用于快速开始常见任务。

模型名称和档位会持续更新，因此本书不再列出固定型号。实际使用时，以模型选择菜单中的名称、说明和当前账号可用范围为准。

一个便于检查的任务描述可以写成：

```text
【目标】我要完成什么，结果给谁使用
【材料】使用哪些文件，哪份材料是事实依据
【交付】需要文档、表格、PPT、网页，还是其他格式
【验收】哪些结果必须准确，哪些操作必须由我确认
```

这四项是任务描述方法，并不是界面中固定存在的四个字段。

## 扩展不是“工作台模式”

官方截图中的“扩展”展开后包含三项：

- **专家套件**：针对岗位或行业场景组织的一组专业能力；
- **技能**：可复用的任务方法与能力；
- **连接器**：把千问办公连接到外部平台、账号、数据或工具。

设计、幻灯片和写作属于官方帮助中心单独介绍的垂类工作台，但它们不是截图所示主页上的“四种模式”。旧版正文把“通用、设计、幻灯片、写作”写成固定四模式并不准确，现已删除。具体垂类工作台是否可用，应以当前端显示为准。

## 一个 3 分钟界面练习

1. 点击“新任务”。
2. 使用输入框左下角的“+”添加一份不含敏感信息的文档。
3. 输入：`请只依据这份文件，用三句话总结主要内容，并列出两个仍需人工确认的问题。`
4. 检查回答是否能在原文中找到依据。
5. 在“最近任务”中找到刚才的任务，确认它可以被重新打开。

完成这一步，你就走通了“添加材料 → 提交任务 → 核对结果 → 返回历史任务”的最小链路。下一章会在这个真实界面基础上完成一次可验收的交付。
