# 第 3 章 认识界面：任务、工作台与扩展

千问办公的界面以"任务"为中心。这一章把每个入口的作用讲清楚，之后所有案例都会反复用到它们。

## 界面入口速览

| 入口 | 用途 | 常用程度 |
|-|-|-|
| 新任务 | 提交目标、背景、素材、交付格式和验收要求 | 每天 |
| 工作台 | 在通用、设计、幻灯片和写作模式之间选择 | 每天 |
| 最近任务 | 返回历史任务，继续补充、修改或检查结果 | 每天 |
| 扩展 | 管理专家套件、连接器和技能 | 每周 |
| 定时任务 | 设置周期性自动执行的任务 | 每周 |
| 我的网页 | 查看和管理已发布的网页产物 | 按需 |
| 个人网盘 | 管理上传资料和千问办公生成的文件 | 每天 |
| IM 频道 | 把桌面端接入钉钉、飞书、微信、Slack 等消息平台 | 按需 |

## 新任务输入区：任务的起点

新任务输入区是你和千问办公对话的主入口。一个高质量的任务描述通常包含四段：

```text
【目标】我要完成什么，给谁用
【材料】我提供了哪些文件，哪份是唯一事实来源
【格式】要 Word、Excel、PPT、网页还是报告，有什么结构要求
【验收】怎样算做对了，哪些地方必须保留人工确认
```

输入区的 **+ 菜单**可以上传本地文件、从个人网盘选择文件；支持多智能体模式的端还会显示模式切换入口。

**上传文件的两个习惯**：

- 事实性材料（数据表、制度文件）直接上传或放进网盘，不要只靠口头描述。
- 每次只给当前任务需要的文件。材料越多，AI 越容易被无关信息带偏。

## 工作台：四种模式

| 模式 | 适合的任务 |
|-|-|
| 通用 | 调研、分析、综合类任务 |
| 设计 | 封面、海报、视觉素材 |
| 幻灯片 | PPT 结构与版式打磨 |
| 写作 | 长文档、报告、文案 |

模式影响的是产出倾向和界面提示，不是硬性限制。做 PPT 时选幻灯片模式、写长文时选写作模式，通常能少返工一次。

## 模型选择器

输入区可以打开模型选择器。较新版本列出**基础、高级和 Qwen3.8-Max-Preview** 三档，具体选项以当前端为准。

一句话原则：**流程性任务用基础档，决定产物质量的关键步骤用高级档**。详细策略见第 5 章。

## 个人网盘：产物的家

千问办公生成的文件和上传的资料都可以在个人网盘管理。建议建立自己的目录规则，例如：

```text
/输入材料/2026-08 销售数据
/产物/周报
/产物/对外发布
/模板
```

产物只有归档后才是资产。散落在各个任务里的文件，下次一定找不到。

## 扩展页：套件、技能与连接器

扩展页集中管理三类可复用能力：

- **专家套件**：面向岗位或行业的完整方案包（第 6 章）。
- **技能（Skill）**：单项专业知识或工作方法。
- **连接器**：对接外部系统，如浏览器、电商平台、MCP 服务（第 8 章）。

当前端没有显示的入口不要视为已开放——不同端、不同套餐、不同组织的可用能力可能不同。

## 一个 3 分钟热身练习

1. 打开新任务输入区。
2. 上传任意一份你手边的文档（一份通知、一张表都行）。
3. 输入：`请阅读这份文件，用三句话总结它讲了什么，并列出两个你认为最需要确认的问题。`
4. 检查回答是否贴合原文，然后把这个任务保留在"最近任务"里。

这个练习不产出正式成果，但它让你完整经历了"输入材料 → 执行 → 检查"的最小循环。下一章，我们把它升级为一个真正可验收的任务。
