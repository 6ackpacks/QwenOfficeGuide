# 第三篇 进阶篇：把案例变成自己的工作系统

第二篇的案例跑通之后，你和"偶尔用一下 AI"的人只差三步：把经验沉淀成 Skill、把任务编排成流水线、把自动化变得可靠。

## 本篇地图

| 章节 | 解决的问题 |
|-|-|
| 第 20 章 打造自己的 Skill | 把你的工作方法变成可安装、可分享的套件 |
| 第 21 章 多任务编排 | 复杂任务自动拆解、多线并行、进度可跟踪 |
| 第 22 章 自动化的可靠性 | 验收、日志、异常处理与回退 |

## 进入本篇的前提

- 至少完整跑通过第二篇的 3 个案例。
- 已经有一批反复使用的提示词（它们就是 Skill 的原料）。
- 清楚自己的任务里哪些步骤必须人工把关。
