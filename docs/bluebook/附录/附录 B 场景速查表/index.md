## 常见错误速查

| 现象 | 可能原因 | 处理 |
|-|-|-|
| 数字对不上 | 口径没说清 | 回第 11 章，先定口径 |
| 输出像万能模板 | 任务五问没写全 | 回第 4 章 |
| 返工越改越差 | 每次从头重生成 | 用差异修改模板 |
| 积分消耗太快 | 全程高级档 + 材料过多 | 回第 5 章 |
| 定时任务静默失败 | 没配失败通知 | 回第 22 章 |
| 文件操作出事故 | 没备份没试跑 | 回第 19 章 |
| 套件装了没效果 | 依赖的连接器没授权 | 回第 6、8 章 |
| 引用来源打不开 | AI 编造或链接过期 | 证据表 + 来源抽检 |
