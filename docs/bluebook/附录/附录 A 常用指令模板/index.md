# 附录 A 常用指令模板

## 通用任务骨架（任务五问法）

```text
【目标】这份成果要帮助谁做什么决定：____
【材料】事实来源文件：____；仅参考：____
【格式】产物类型与结构要求：____
【验收】怎样算做对了：____
【边界】不要做什么：____
```

## 文档生成

```text
基于附件材料生成一份【文档类型】：
结构：____；语气：____；篇幅：____。
要求：结论必须有材料出处，引用不到标注"待补充"；
先给大纲确认，再写全文。
```

## 差异修改

```text
在上一版基础上修改，不要重新生成：
1. ____；
2. ____；
3. 输出 vN 版，并列出本次改动清单。
```

## 数据分析

```text
对附件表格先做数据体检（不要直接分析）：
规模、字段、空值/重复/异常、口径疑点。
输出体检报告和清洗建议，等我确认后执行。
```

## 调研报告

```text
调研主题：____。
第一步：把需求拆成 6-8 个具体问题，等我确认；
第二步：检索并输出证据表（信息点、来源、日期、可信度）；
第三步：基于证据表成稿，无证据的判断单独放"观点与假设"。
```

## 定时任务

```text
创建定时任务：
- 频率：____（如工作日每天 08:30）
- 输入：____
- 动作：____
- 推送：____
- 失败处理：如实报告缺失，绝不编造数据。
```

## 批量文件操作

```text
对【目录】执行【操作】：
1. 先在样本目录试跑并报告结果；
2. 全量执行时每步操作记入日志文件；
3. 不删除任何文件，异常项移入待确认目录；
4. 完成后输出执行报告。
```

## 会议听记整理

```text
整理会议听记为纪要：
结构：主题时间、参会人、讨论要点、决议、待办、遗留问题。
决议必须写明谁、做什么、何时完成，缺一标"待确认"；
分歧如实保留，不猜测发言人。
```

## 网页制作

```text
制作免部署网页：
【内容】____；【交互】____；【数据】____；【视觉】____。
先给页面结构和视觉方案确认，再制作，最后发布并给我链接。
```

## 执行总结

```text
请总结本次任务的执行情况：
完成了什么、使用了哪些材料、哪些步骤被跳过或失败、
产物存放在哪里、还有哪些待人工确认。
```
