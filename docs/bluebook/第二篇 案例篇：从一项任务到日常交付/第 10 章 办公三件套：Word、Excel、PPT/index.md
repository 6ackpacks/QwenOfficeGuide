# 第 10 章 办公三件套：Word、Excel、PPT

办公三件套是多数人第一次感受到千问办公价值的地方。

千问办公的产物交付能力强调两点：**一站生成**——PPTX、Word、Excel、HTML 等产物直接产出；**可继续编辑**——原生支持 Office 套件预览与实时编辑，生成不是终点。

## 共同工作流：先把五个问题说清

无论文档类型是什么，都建议先按第 4 章的任务五问法拆任务：目标、受众、材料、格式、验收。

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 这份材料要帮助谁做什么决定 | 给部门负责人看，用于判断项目是否继续投入 |
| 受众 | 阅读者是谁，懂不懂背景 | 管理层只看结论；项目组需要过程和责任人 |
| 材料 | 哪些文件是事实来源，哪些只是参考 | `data.xlsx` 是唯一数据口径，旧版 PPT 只参考结构 |
| 格式 | 要 Word、Excel、PPT，还是三者联动 | 一份复盘 Word、一张风险台账 Excel、一份 8 页汇报 PPT |
| 验收 | 怎么判断结果可用 | 数字能回到源文件，表格公式可刷新，PPT 投屏不溢出 |

## Word：从空白页到正式文档

### 这个场景的痛点

Word 看起来只是写字，但真实办公里的难点通常有四个：不知道该按什么结构写、语气不够正式、标题和编号混乱、内容没有证据来源。

千问办公适合解决的不是"替你拍脑袋"，而是把已有材料变成结构稳定、语气一致、可以继续修改的文档初稿。

### 适合交给 Word 的任务

- **正式方案**：活动策划、项目方案、营销方案、培训方案。
- **管理文档**：制度、通知、申请、会议纪要、复盘报告、周报月报。
- **产品材料**：PRD、需求说明、竞品分析、用户访谈总结。

### 提示词示例：生成一份项目复盘 Word

```text
帮我生成一份项目复盘的 Word 文档。
材料：附件的项目计划表、周报汇总和结项数据。
结构：背景与目标、关键结果、做对了什么、问题与原因、后续行动建议。
要求：
1. 结论必须有材料出处，引用不到的数据标注"待补充"；
2. 语气正式简洁，适合提交给部门负责人；
3. 问题归因只基于材料，不要猜测人的动机。
```

### 二次修改不要重写，要说差异

```text
在上一版复盘 Word 基础上修改，不要重新生成整篇：
1. 关键结果部分压缩为 5 条以内，每条不超过 50 字；
2. 问题与原因改为表格：问题、影响、原因、责任人、状态；
3. 补充一节"风险预案"，覆盖进度、预算和人员变动三类；
4. 输出 v2 版文档，并列出本次修改清单。
```

## Excel：把表格变成能回答问题的分析

### 这个场景的痛点

Excel 的问题通常不在"会不会做图"，而在"这个表到底能回答什么问题"。很多表格混着日期、文本、空值、合并单元格和多个口径，直接让 AI 分析，很容易得到一份看似专业、其实没有业务价值的图表。

**先定义业务问题，再决定图表，而不是先生成漂亮图。**

### 适合交给 Excel 的任务

- **数据清洗**：去重、补空值、统一日期格式、拆分字段、合并多表。
- **经营分析**：销售额、利润率、转化率、客单价、库存周转。
- **报表生成**：周报、月报、预算执行、考勤汇总、项目台账。
- **公式辅助**：生成或解释复杂公式，排查错误值。

### 提示词示例：清洗并分析销售表

```text
请处理附件的销售明细表：
1. 先告诉我数据质量问题（空值、重复、日期格式不一致等），给出处理方案，
   等我确认后再动手；
2. 清洗后按品类和月份做透视汇总，公式保持可刷新；
3. 标出环比下滑超过 20% 的品类；
4. 输出一份清洗后的 Excel 和一段 200 字以内的结论摘要。
不要直接删除原始行，被剔除的数据放到单独的"剔除记录"工作表。
```

## PPT：把结论讲清楚

### 这个场景的痛点

PPT 的常见问题不是不够好看，而是"一页讲不清一件事"。让 AI 做 PPT 时，先给结论和结构，再谈视觉。

### 提示词示例：从数据到汇报 PPT

```text
基于附件的月度经营分析 Excel，生成一份给管理层看的汇报 PPTX：
1. 8-10 页：封面、核心结论（一页讲完）、关键指标、亮点、问题、归因、下月计划、附录；
2. 每页一个观点，标题直接写结论，不要写"销售分析"这种空标题；
3. 图表从 Excel 数据生成，数字必须与源表一致；
4. 配色用公司标准的深蓝+白（参考附件模板）。
先给我大纲确认，再生成完整 PPT。
```

## 三件套联动

很多真实任务需要三者配合。一个常见的联动链路：

```mermaid
flowchart LR
    A[原始数据 Excel] --> B[清洗与透视]
    B --> C[分析结论]
    C --> D[汇报 PPT]
    C --> E[详细说明 Word]
    D --> F[会议汇报]
    E --> F
```

联动任务的提示词要点：**指定唯一数据口径**。例如"三个文件的所有数字必须来自 `data-v3.xlsx`，任何一处不一致以该文件为准"。

## 避坑清单

- 数字必须抽查回源，尤其是 AI"总结"出来的百分比。
- PPT 生成后要投屏预览，检查文字溢出和图表清晰度。
- Excel 透视表和公式要在本地刷新一次，确认没有断链。
- 对外正式文档的落款、日期、密级标注，必须人工确认。
- 涉及客户名、金额、人员信息的内容，发送前再核一遍。
