# 第二篇 案例篇：从一项任务到日常交付

这一篇用十个真实工作场景，演示千问办公的六大核心能力如何组合成日常交付。

## 难度地图

| 等级 | 案例 | 核心能力 |
|-|-|-|
| L1 | 10. 办公三件套 | 可编辑产物、任务五问、差异返工 |
| L1 | 11. 数据分析 | 表格清洗、可视化、报告 |
| L2 | 12. 信息调研 | 搜索、证据表、行业报告 |
| L2 | 13. 网页交付 | 免部署网页、看板、发布 |
| L2 | 14. 多模态创作 | 图文音视频生成 |
| L2 | 15. 会议生产力 | 钉钉听记、纪要、待办 |
| L2 | 16. 日常自动化 | 定时任务、简报推送 |
| L3 | 17. 电商运营 | 数据聚合、选品、经营分析 |
| L3 | 18. 内容增长 | 选题、素材、多平台闭环 |
| L3 | 19. 本地文件与电脑操作 | 批量处理、授权边界 |

## 怎么读这一篇

- 每章都按"痛点 → 流程 → 提示词 → 验收 → 边界"展开，可以直接照着做。
- 提示词都是模板：把【】里的内容换成你的实际情况再执行。
- 每章结尾都有"避坑清单"，那是这一章最值钱的部分。
