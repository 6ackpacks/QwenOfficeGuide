# 第 19 章 本地文件与电脑操作：批量处理桌面文件

桌面客户端的本地文件能力，是千问办公区别于纯网页工具的分水岭。这一章用"整理一堆混乱文件"这个人人都有痛点的任务，演示批量处理的完整方法。

## 场景

你的"下载"文件夹或项目文件夹里堆着几百个文件：命名混乱、格式混杂、没有目录结构。你需要把它们变成可检索的资产。

## 安全第一步：备份与授权

任何批量文件操作之前：

1. **备份**：把目标文件夹整体复制一份（或压缩存档）。
2. **授权范围**：只把需要整理的文件夹授权给千问办公，不要给整个磁盘。
3. **试跑**：先让 AI 在 10 个文件的样本上演示方案。

## 完整流程

### 第一步：盘点

```text
请扫描【项目资料】文件夹（含子目录），只做盘点不做修改：
1. 文件总数、类型分布（按扩展名）；
2. 目录结构现状；
3. 命名模式：哪些有规律、哪些完全混乱；
4. 疑似重复文件（按文件名和大小初筛）；
5. 输出一份盘点报告。
```

### 第二步：方案确认

```text
基于盘点结果给出整理方案：
1. 目录结构设计（按项目/年份/类型，说明理由）；
2. 命名规则：统一为"日期_项目_内容_版本"格式；
3. 重复文件处理建议；
4. 无法归类的文件放哪里。
输出方案文档，我确认后再执行。
注意：方案中列出每一步会移动/重命名多少文件。
```

### 第三步：样本试跑

```text
先在 /样本测试/ 目录（我已复制 20 个文件进去）执行方案，
完成后报告：成功多少、失败多少、失败原因。
确认无误后我再授权全量执行。
```

### 第四步：全量执行与日志

```text
对【项目资料】全量执行已确认的方案：
1. 每移动/重命名一个文件都记入 rename-log.csv
   （原路径、新路径、操作类型、时间）；
2. 不删除任何文件，重复文件移入 /待人工确认/ 目录；
3. 遇到被占用或权限不足的文件跳过并记录，不要中断整体流程；
4. 完成后输出执行报告。
```

## 电脑操作的补充场景

对于没有文件接口的应用（比如某些本地软件的导出功能），可以用第 8 章的电脑操作能力：让千问办公看着界面、点按钮完成重复操作。原则不变：**先试跑、有日志、人看着**。

## 避坑清单

- 永远先备份。"AI 把我的文件删了"是最无法挽回的事故。
- 整理方案必须人工确认后再全量执行，别嫌麻烦。
- 日志文件是后悔药，移动重命名类操作必须留痕。
- 涉及合同、发票、财务文件时，整理可以自动，归档位置要人定。
- 整理完成后，把目录结构和命名规则写成文档——否则三个月后又乱了。
