# 第 13 章 网页交付：免部署网站与数据看板

千问办公的网页交付能力可以做**带数据库与交互逻辑的免部署独立网页**，覆盖设计、开发、数据接入和在线发布，全流程一站式交付。对不会写代码的人来说，这是最接近"超能力"的一项。

## 能做什么

| 类型 | 例子 |
|-|-|
| 展示页 | 产品介绍页、活动页、个人简历页 |
| 表单与收集 | 报名表、问卷、需求收集 |
| 数据看板 | 经营日报页、项目进度看板 |
| 轻量应用 | 带数据库的小工具（登记、查询、抽奖） |
| 内容发布 | 持续更新的资讯页、简报页 |

发布后的网页在**我的网页**里管理；可发布数量按套餐分配（免费版 5 个，标准版 10 个，高级版 50 个，以官网为准），付费版还支持访问密码与数据库存储。

## 完整流程：做一个活动报名页

### 第一步：描述需求

```text
请制作一个免部署的活动报名网页：
【内容】活动名称、时间地点、嘉宾介绍、议程表、报名入口；
【交互】报名表单收集：姓名、公司、职位、手机号、想听的主题（多选）；
【数据】报名信息写入网页数据库，我之后可以导出；
【视觉】简洁商务风，主色深蓝，移动端友好；
【交付】先给我页面结构和视觉方案确认，再制作，最后发布并给我链接。
```

### 第二步：预览与修改

生成后先在预览里点一遍：表单能不能提交、移动端会不会错位、文案有没有错别字。修改继续用差异描述：

```text
修改报名页，不要重做：
1. 嘉宾介绍改为两列卡片布局；
2. 表单增加"如何得知本次活动"下拉项；
3. 页脚补充主办方名称。
```

### 第三步：发布与管理

确认无误后发布。后续管理动作：

- 在"我的网页"查看访问情况、更新内容或下线页面。
- 需要限制访问时，用访问密码（付费版支持）。
- 报名数据定期导出备份，不要只存在网页数据库里。

## 数据看板：把定时任务装进网页

把第 9 章的定时任务和网页交付结合起来：

```text
把之前每天早上生成的行业简报做成一个持续更新的网页：
1. 最新一期置顶，历史期归档可翻；
2. 每次定时任务完成后自动更新这个网页；
3. 页面顶部显示"最后更新时间"。
```

这样团队只需要收藏一个链接，就能看到最新的自动产物。

## 避坑清单

- 发布前检查敏感信息：测试数据、内部姓名、手机号都不要留在页面上。
- 对外网页的文案责任在人，AI 写的宣传语要人工确认不夸大、不侵权。
- 表单收集个人信息时，页面要有用途说明；不再使用的表单及时下线。
- 网页数量是套餐资源，废弃页面记得删除释放额度。
