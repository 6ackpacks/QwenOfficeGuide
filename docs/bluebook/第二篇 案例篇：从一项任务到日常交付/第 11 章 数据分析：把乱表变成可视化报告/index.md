# 第 11 章 数据分析：把乱表变成可视化报告

调研与数据分析是千问办公的核心能力之一：分析在线或本地数据并生成可视化结果。这一章用一条完整链路演示：乱表 → 清洗 → 分析 → 图表 → 报告。

## 场景

你手上有一份从系统里导出的销售明细（或任何一张真实的乱表），领导要一份"能直接看懂"的分析报告，明天早上开会用。

## 完整流程

```mermaid
flowchart LR
    A[上传乱表] --> B[数据体检]
    B --> C[确认口径]
    C --> D[清洗与整理]
    D --> E[分析与可视化]
    E --> F[报告成稿]
    F --> G[人工抽检]
```

### 第一步：数据体检，先别急着分析

```text
请对附件的销售明细做数据体检，先不要分析：
1. 行列规模、字段清单和每列的数据类型；
2. 空值、重复值、异常值（如负数金额、未来日期）的分布；
3. 疑似口径问题：同一字段多种写法、单位不一致等；
4. 给出清洗建议清单，标注每条建议会影响多少行。
输出体检报告，等我确认后再清洗。
```

这一步的价值：**让你知道数据可信到什么程度**。很多错误结论不是分析方法错，而是数据本身有问题。

### 第二步：确认口径

体检后通常要跟 AI 对齐口径，例如：

```text
确认以下口径：
1. 销售额以"实付金额"列计算，排除已退款订单；
2. 时间范围取 2026-07-01 至 2026-07-31；
3. 品类按"一级类目"字段归并，字段为空的归入"未分类"并单独说明。
按此口径继续。
```

### 第三步：分析与可视化

```text
基于清洗后的数据完成分析：
1. 总体趋势：日销售额曲线，标注波峰波谷；
2. 品类对比：销售额 top10 品类柱状图 + 各品类毛利率；
3. 异常检测：环比波动超过 ±20% 的品类，列出可能相关的订单特征；
4. 图表要求：中文标签、坐标轴有单位、配色统一；
5. 输出：一份可视化图表为主的分析报告（HTML 或 Word 均可），
   以及一份汇总数据的 Excel。
所有图表数字必须可追溯到清洗后的表。
```

### 第四步：验收

- 抽 3 个图表数字回到 Excel 核对。
- 检查时间轴是否连续、有没有把退款算进销售额。
- 看结论是否只基于数据——出现"可能是因为市场竞争加剧"这类无依据猜测时，要求删除或标注"假设"。

## 进阶：多表关联

真实工作里常常不止一张表：

```text
我有三张表：销售明细、商品主数据、门店信息。
请用商品编码和门店编码关联三表（先报告各表关联字段的匹配率，
匹配率低于 95% 时停下来等我确认），
然后按"门店 × 品类"输出销售热力分析。
```

## 避坑清单

- 永远先体检再分析；跳过体检的分析报告是空中楼阁。
- 口径确认要留痕，写在任务描述里，不要只在口头。
- 可视化不是越多越好，一张图只回答一个问题。
- 异常值的处理（剔除还是保留）必须人工拍板。
- 报告里的每个"下降/上升"，都要有对比基准（环比、同比还是预算）。
