# 第 17 章 电商运营：选品、商品洞察与经营分析

千问办公的数据聚合能力接入了 1688 等电商后台、小红书等社交媒体，可以跨来源聚合经营与内容数据，支持选品、商品洞察和经营分析。这一章用三个电商高频任务演示。

## 前提：连接器授权

电商类任务开始前，先在扩展页确认相关连接器已开启并完成账号授权。授权时看清范围：只读数据、还是会操作店铺？本蓝皮书建议**经营分析类任务只开只读权限**。

## 任务一：选品调研

```text
我要在【家居收纳】类目选新品。请：
1. 通过电商数据查看该类目近 30 天的热销商品特征：
   价格带、销量区间、主要卖点关键词；
2. 找出增长快但竞争相对少的细分（给出判断依据）；
3. 结合小红书等平台的相关内容热度，验证需求是否真实；
4. 输出选品报告：候选清单（含价格、销量、卖点、风险）、
   数据来源说明、建议验证动作。
不要给出"保证爆款"式结论，所有判断标注置信度（高/中/低）。
```

## 任务二：商品洞察

```text
分析我们店铺【商品 A】最近 30 天的表现：
1. 流量、转化、销量趋势，标注异常日期；
2. 评价中的高频好评点与差评点，各列 5 条并附原文摘录；
3. 与类目同价格带竞品对比（用公开可见信息）；
4. 输出：一页诊断结论 + 3 条可执行的优化建议。
```

## 任务三：经营日报自动化

把经营分析做成每日例行公事：

```text
创建经营日报任务（工作日每天 09:00）：
1. 汇总昨日店铺核心指标：销售额、订单量、客单价、退款率；
2. 与上周同日对比，波动超过 ±15% 的指标标红并附简要原因假设；
3. 生成 Excel 明细 + 一页图文摘要，推送到运营群；
4. 指标口径以附件的口径说明为准，口径之外的字段不要自行发挥。
```

## 经营分析的口径纪律

电商数据最容易出错的地方是口径：

| 易混点 | 必须说清 |
|-|-|
| 销售额 | 下单口径还是实付口径，含不含退款 |
| 时间 | 按下单时间还是支付时间 |
| 退款 | 统计周期内按发生还是按归属订单 |
| 渠道 | 多店铺是否合并，跨店优惠怎么分摊 |

把口径写成一份文档放进网盘，每次任务都引用它——这比在提示词里重复写十遍更可靠。

## 避坑清单

- 涉及店铺后台的操作类授权（改价、上下架）尽量不用自动化，必须用时逐次人工确认。
- 竞品分析只用公开信息，不爬取对方后台，不违反平台规则。
- 平台数据和第三方工具有出入时，以店铺后台为准。
- 选品结论要留验证动作（小批量试销），不要把报告当决策本身。
