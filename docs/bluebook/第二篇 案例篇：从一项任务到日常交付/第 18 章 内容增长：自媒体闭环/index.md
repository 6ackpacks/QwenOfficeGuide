# 第 18 章 内容增长：自媒体闭环

自媒体不是靠单篇爆款，而是靠一条可重复的闭环：选题 → 素材 → 成稿 → 多平台适配 → 发布 → 复盘。千问办公的技能市场有**内容增长 GROWTH KIT**，本章演示如何手动搭出这条闭环。

## 闭环全景

```mermaid
flowchart LR
    A[选题池] --> B[资料与证据]
    B --> C[长文成稿]
    C --> D[多平台适配]
    D --> E[发布]
    E --> F[数据复盘]
    F --> A
```

## 第一步：选题池

```text
我在运营一个【AI 办公工具】方向的账号，受众是【职场新人】。
请生成本周选题池：
1. 10 个候选选题，每个附一句"读者为什么要看"；
2. 标注每个选题的内容形式（教程/盘点/观点/案例）；
3. 结合近期平台热点，但不追与工作无关的热度。
输出表格，我挑选后进入下一步。
```

## 第二步：成稿

```text
选定题目《用千问办公把周报时间从 2 小时压到 10 分钟》，请写公众号长文：
1. 结构：痛点开场 → 操作步骤（带提示词）→ 效果对比 → 注意事项；
2. 所有操作步骤必须真实可执行，不确定的功能标注"以当前版本为准"；
3. 1500-2000 字，口语化但不油腻；
4. 同时给出 3 个备选标题。
```

## 第三步：多平台适配

```text
基于已定稿的文章生成：
1. 小红书版：封面文案（大标题 + 副标题）、正文（带话题标签）、3 张内页图；
2. 短视频版：60 秒口播稿 + 分镜建议；
3. 社群版：100 字以内的导语，引导点击阅读原文。
各平台内容独立成稿，不要直接复制粘贴。
```

## 第四步：复盘回流

```text
这是上周 5 篇内容的数据（阅读、点赞、收藏、转发、涨粉）。
请分析：
1. 哪类选题和标题表现更好，给出证据；
2. 数据最差的篇目，问题可能出在哪个环节；
3. 输出下周选题建议，保留有效方向，砍掉连续两周垫底的方向。
```

## 人工必须守住的三个关口

1. **事实关口**：教程里的每个步骤发布前自己跑一遍。
2. **合规关口**：不夸大宣传、不蹭未授权的热点、广告内容要标注。
3. **账号关口**：发布动作本身由人完成；自动发布必须逐条确认，不要让 AI 直接登录账号乱发。

## 避坑清单

- 选题贪多嚼不烂，一周 3-5 个候选足够。
- AI 初稿的"正确废话"要删，留下你的真实经验和数据。
- 多平台适配不是改字数，是改表达方式。
- 复盘看趋势不看单篇，一次爆款或扑街都不构成结论。
