## 投稿你的案例

如果你用千问办公解决了一个真实问题，欢迎把案例写下来提交 PR。一个合格的案例至少包含：

- **场景与问题**：谁在什么任务中遇到了什么困难。
- **任务描述**：你输入的任务描述（提示词）原文。
- **执行过程**：关键步骤、授权要求和人工关口。
- **实际效果**：产物截图或结果说明。
- **验收标准**：怎样判断任务正确完成。
- **避坑记录**：你踩过的坑和解决办法。
